第一次設定

同學不需要 GitHub 帳戶也能上傳，因為網站會代他們把檔案寫入你的儲存庫。為此需要一把只能存取這個儲存庫的「權杖」（token）。權杖會先用密碼加密，才儲存到網站。

  1. 在 GitHub 建立權杖

    以儲存庫擁有者的帳戶登入 GitHub，然後按下面的按鈕。名稱、有效期和權限已經預先填好，你只需要：

    • 在「Repository access」選 Only select repositories，然後只選
    • 確認「Permissions」內 Contents 是 Read and write
    • 按「Generate token」，複製以 github_pat_ 開頭的一串文字
    前往 GitHub 建立權杖

  2. 貼上權杖

  3. 設定兩個密碼

    告訴同學，上傳時需要輸入。最少 8 個字元。

    只有你知道，用來登入這一頁。最少 10 個字元。

    加密後的權杖存放在公開的網站上，密碼越難猜越安全。請混合英文字母和數字，不要使用學校名稱、班別或年份等容易猜到的字詞。

    密碼和權杖

    密碼可能外洩了？只更改密碼並不足夠，因為舊的加密資料仍留在儲存庫的歷史記錄內。請到 GitHub 刪除舊權杖，再在這裡換上新權杖。權杖到期後，也需要更換一次。
